# Minecraft 1.21.1 - 1.1.2

[English](#english) | [中文](#中文)

## English

### Added

- **Hotbar switching modes:** press **X** to swap the hotbar with a chosen inventory row (Specific Row), or to rotate all three inventory rows and the hotbar (Cycle) in Forward or Reverse direction. Both options are set in **Alt + X → Item Switching**.

### Changed

- Outlines are drawn as real cuboid beams instead of GL lines: crosshair-follow targets and in-progress ranges use `0.020F`, committed blueprint selection edges use `0.010F`, and the follow box is hidden between the first and second point.
- Blueprint build ghosts now match Create's schematic preview: full-bright blocks with their original textures and colors, no surface tint, hidden faces culled, and correct water/cloud ordering. Valid and invalid previews are shown by outline color only.
- The committed blueprint selection is now light orange instead of orange, and it stays easy to tell apart from the expand (pale yellow) and shrink (light red) previews.
- The blueprint build ghost now appears 4 blocks in front of you by default instead of 8; scrolling still adjusts the distance.

### Fixed

- Fixed outlines turning dark when another rendering mod leaves the global color modulator modified; the shader color is now restored before drawing outlines, and ghost rendering restores its render state in a `finally` block.
- Fixed outline rendering under Iris: custom lines use an immediate `ByteBufferBuilder` source instead of Iris's deferred `FullyBufferedMultiBufferSource`, so they are drawn in the correct render stage.
- Fixed the Chain Mining target box being only one pixel wide on drivers that clamp GL line width; it is now built from cuboid beam quads.
- Fixed the Blueprint selection preview becoming uniformly dark or changing brightness under Iris shaders; the selection now draws outlines only, so the world keeps its normal shader lighting. The build ghost also uses real world lighting.

**Environment:** Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21. Tested in a vanilla-like environment only (singleplayer / integrated server).

## 中文

### 新增

- **物品切换模式**：按 **X** 可以把快捷栏和指定背包行互换（指定行），或者让背包三行和快捷栏按正序 / 倒序轮换（循环）。两项都在 **Alt + X → 物品切换** 中设置。

### 修改

- 轮廓改为用 cuboid 边条几何体绘制，不再依赖 GL 线宽：准星跟随目标和正在操作的选区 / 规划预览使用 `0.020F`，已确定的蓝图选区轮廓使用 `0.010F`，跟随框在选下第一个点、第二个点确定前隐藏。
- 蓝图建造虚影对齐 Create 蓝图预览：方块使用满亮光照、原始贴图和颜色，不叠加表面色，剔除隐藏面，水面 / 云层前后关系正确；有效 / 无效仅通过轮廓线颜色区分。
- 蓝图绘制中已确定选区由橙色改为浅橙色，仍和扩选（浅黄）、缩选（浅红）预览容易区分。
- 蓝图建造虚影的默认距离由视线前方 8 格改为 4 格，滚轮仍可调整。

### 修复

- 修复其它渲染模组遗留颜色调制状态时轮廓发暗的问题；绘制轮廓前恢复着色，虚影渲染在 `finally` 中恢复渲染状态。
- 修复 Iris 着色器下的轮廓渲染：轮廓线改用独立的立即绘制 `ByteBufferBuilder`，不再经过 Iris 的延迟 `FullyBufferedMultiBufferSource`。
- 修复连锁破坏的瞄准方块框在部分显卡驱动上只能显示 1 像素细线的问题；改为用 cuboid 边条生成有实际宽度的粗框。
- 修复蓝图选区预览在 Iris 着色器下整片变暗或亮度异常的问题；选区只绘制轮廓，世界保持正常着色器光照，建造虚影也使用真实光照。

**环境要求：** Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21；仅在原版条件下测试（单人游戏 / 内置服务器）。
