# Minecraft 1.21.1 - 1.1.3

[English](#english) | [中文](#中文)

## English

### Added

- **Fluid tank on every blueprint box tier** (2000 mB up to 64000 mB): a vertical gauge in the box screen. Stored fluid uses the fluid's own color, the part the blueprint still needs shows a pale version of it, and unused capacity stays disabled. Hover a section to see the stored amount, capacity and requirement.
- **Bucket clicks:** an empty bucket plus a click on a fluid section takes one bucket out; a filled fluid bucket plus a click on the tank stores one bucket.
- **View toggle** left of the tank: raised shows the box materials, pressed shows the items inside containers found in the blueprint. Both columns accept items.
- **Record Container Items option** in the blueprint page (on by default): turn it off to record structures with empty containers.
- **Chain mining blacklist**: a toggle under the chain limit opens an inventory-style grid (5 of 16 rows, scrollable) of the blocks that use the preset plan; left click selects, right click deselects, Delete removes them, and Add closes the screen so you can pick a block in the world with a white outline.
- **Quick build default distance:** when no block is targeted, the indicator distance can be changed with **Ctrl** + scroll between 2 and 8 blocks.

### Changed

- Blueprint box capacities stay 27 / 45 / 63 / 81 / 108 / 144 slots; the container-content column has 9 / 18 / 27 / 36 / 45 / 54 slots.
- The three box buttons (Clear / Quick Take / Store All) moved to the right of your inventory.
- Recording a blueprint in cut mode now stores fluid sources in the tank instead of consuming empty buckets; if the tank is too small, the blueprint is not created.
- Building takes fluid from the tank. Container contents are no longer required materials: put them in the second column and they are restored into the built containers as far as they are available. If they do not fit in the content column, recording is refused with a message instead of truncating them.
- The tank is capped per fluid at the blueprint requirement, uses the fluid texture's color, and build previews show fluid sources as translucent blocks.
- The view toggle is a vanilla-style chest button and the right-hand buttons are narrower.
- Which blocks use the preset chain plan now comes from the per-player blacklist; the settings tabs are narrower and the divider moved left for more content room.
- The chain mining page drops its "Massive Blocks" heading, the blacklist scroll groove lines up with its thumb, the blueprint tank uses a vanilla-style 1-pixel edge instead of an outer frame, the three blueprint box buttons line up with the tank, and two key-binding names were clarified.
- Shulker boxes are recorded the vanilla way: the blueprint stores only the shulker box item, its contents stay inside that item, and the toggle button keeps its vanilla look without an outer black border.

### Fixed

- Fixed the container-content column reusing the material column's rows: it now shows only its own rows (one row on the base box, two on copper, ...).
- Fixed shulker boxes losing their contents when recorded.
- Fixed the build ghost being covered by clouds and showing every face; it now renders after the clouds and only shows the side facing you.
- Chain mining and quick build presets now switch with **Alt + scroll** while that mode is on.

**Environment:** Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21. Tested in a vanilla-like environment only (singleplayer / integrated server).

## 中文

### 新增

- **每一级蓝图箱都有流体储罐**（2000 mB 到 64000 mB）：界面里一条竖着的刻度条，已存流体用流体本身的颜色显示，蓝图还需要但没放进去的部分显示同色浅色，未使用的容量保持禁用底色。悬停一段可以看到存量、容量和需求。
- **桶点击**：空桶点某一段流体可以取出 1 桶；液体桶点储罐可以存入 1 桶。
- **切换按钮**（储罐左边）：凸起显示蓝图箱材料，按下显示蓝图内容器里的物品；两栏都可以放入物品。
- **“记录容器内物品”开关**（蓝图建造页，默认开）：关闭后记录的结构里容器都是空的。
- **连锁破坏黑名单**：连锁数量下面的开关会打开一个类似物品栏的格子（16 行里显示 5 行，可滚动），列出使用预设方案的方块；左键选中、右键取消选中，“删除”移出，“添加”会关闭界面让你在世界里点选方块（白色粗框标出）。
- **快速建造默认位置距离**：准星没有指向方块时，可以用 **Ctrl** + 滚轮在 2-8 格之间调整指示器距离。

### 修改

- 蓝图箱容量保持 27 / 45 / 63 / 81 / 108 / 144 格；第二栏（容器内容物）容量 9 / 18 / 27 / 36 / 45 / 54 格。
- 三个按钮（清空蓝图 / 一键取出 / 一键存入）移到玩家物品栏右边。
- 剪切模式记录蓝图时，流体改为收进储罐，不再消耗空桶；储罐装不下时不会创建蓝图。
- 建造时从储罐取流体；容器内容物不再是必需材料，放进第二栏后会按原容器槽位回填，缺货的部分留空；容器内容物放不进第二栏时，记录会直接提示并取消，不会截断。
- 储罐按蓝图需求限制每种流体的存量，颜色取自流体贴图，建造预览里会把流体源显示为半透明方块。
- 第二栏切换按钮改为原版风格的箱子按钮，右侧按钮变窄。
- 哪些方块使用预设连锁方案改为由玩家自己的黑名单决定；设置界面左侧按钮变窄、分隔线左移，右侧内容区更宽。
- 连锁破坏页去掉“大量方块”标题，黑名单滑槽与滑块对齐，蓝图箱储罐改用原版凹槽边框、三个按钮与储罐右侧对齐，并调整了两个快捷键名称。
- 潜影盒按原版逻辑记录：蓝图只保存潜影盒物品，内容仍在物品里；切换按钮去掉最外层黑边、保持原版外观。

### 修复

- 修复第二栏沿用第一栏行数的问题：现在只按它自己的容量显示行数（蓝图箱 1 行、铜制 2 行……）。
- 修复第二栏行数较少时格子下方残留黑边、区域最下方有黑色宽线的问题。
- 修复潜影盒记录后内容物丢失的问题。
- 修复建造虚影被云层遮挡、并且显示全部面的问题；现在在云层之后渲染，只显示朝向玩家的那一面。
- 连锁破坏和快速建造切换预设改为 **Alt + 滚轮**（该功能开启时生效）。

**环境要求：** Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21；仅在原版条件下测试（单人游戏 / 内置服务器）。
