# Minecraft 1.21.1 - 1.1.1

[English](#english) | [中文](#中文)

## English

### Added

- **`Ctrl + left-click` cut recording:** records the structure, collects the block items, container contents, and fluid buckets into the blueprint box, and clears the source blocks.
- **Follow-target preview:** Quick Build and Blueprint Draw outline the block under your crosshair before the first point is chosen, so you can see that the mode is active.
- **Unified exit key** (default `` ` ``, rebindable): Chain Mining, Quick Build, and Blueprint Build can all be exited with the same shortcut.

### Changed

- `Ctrl + right-click` in draw mode now records the blueprint only (copy): the source blocks stay in place and no materials are put into the box.
- The Automatic Refill page now uses the vanilla chest slot style, matching the blueprint box screen.
- Blueprint build ghosts are slightly more opaque, and faces you cannot see are no longer drawn. The blueprint outline remains fully visible.

### Fixed

- Fixed blueprint drawing being unable to re-add an area after it had been removed with left-click selection; selections are now applied in operation order, so a later add overrides an earlier removal.

**Environment:** Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21. Tested in a vanilla-like environment only (singleplayer / integrated server).

## 中文

### 新增

- **`Ctrl + 左键` 剪切记录**：记录结构，把方块物品、容器内容和流体桶收进蓝图箱，并清除源方块。
- **目标跟随预览**：快速建造和蓝图绘制在第一次选点前会跟随准星显示目标轮廓，便于确认功能已开启。
- **统一退出键**（默认 `` ` ``，可改键）：连锁破坏、快速建造、蓝图建造都能用同一个快捷键退出。

### 修改

- 绘制模式下 `Ctrl + 右键` 改为只记录蓝图（复制）：源方块保持不变，也不会向蓝图箱放入材料。
- 自动补充设置页改用原版箱子界面的槽位样式，和蓝图箱界面保持一致。
- 蓝图建造虚影透明度略微提高，并剔除看不到的面；建造轮廓线仍正常显示。

### 修复

- 修复蓝图绘制中先用左键删除区域、之后再用右键框选同一区域时无法将其加回来的问题；选区现在按操作顺序生效，后一次操作会覆盖前一次。

**环境要求：** Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21；仅在原版条件下测试（单人游戏 / 内置服务器）。
