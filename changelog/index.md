## 索引维护约定

- 一个 Minecraft 版本对应一个二级标题（`##`）。
- 同一 Minecraft 版本下的模组版本放在同一张表里，按版本从新到旧排列。
- “完整日志”列必须使用 Markdown 相对链接，保证在 GitHub / 本地 Markdown 查看器中都能点击跳转。
- 只写对玩家有意义的变更：新增功能、行为变化、问题修复、兼容性说明；内部重构可以简要带过。
