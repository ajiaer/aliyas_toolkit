# Minecraft 1.21.1 - 1.1.2

[English](#english) | [中文](#中文)

## English

> Mod version: `1.21.1-1.1.2`  
> Environment: Minecraft 1.21.1 + NeoForge 21.1.265+ / Java 21  
> Testing: vanilla-like environment only (singleplayer / integrated server)  
> Installation: client and server

### Added

- Hotbar switching now supports **Specific Row** (choose inventory row 1-3, default) and **Cycle** (rotate all three inventory rows and the hotbar). Cycle direction can be Forward or Reverse, and both options are set in **Alt + X → Item Switching**.
- **Specific Row** swaps the nine hotbar slots with the chosen inventory row. **Cycle** rotates in the order row 1 → row 2 → row 3 → hotbar → row 1 (Forward), or the opposite order (Reverse). The swap row is only used in **Specific Row** mode; **Cycle** always rotates all four rows. Both modes work without opening the inventory and do not trigger automatic refill. The switch mode and cycle direction are saved per player with the other settings, and existing player data keeps the default **Specific Row** + **Forward**.

### Changed

- The crosshair-follow target uses a `0.020F` cuboid outline in Chain Mining, Quick Build, and Blueprint Draw. The in-progress range preview also uses `0.020F`; already committed Blueprint selection edges and visible front outlines use a thinner `0.010F` cuboid outline. The follow box is hidden between the first and second selection points in Quick Build and Blueprint Draw.
- Blueprint build ghosts now follow Create's schematic preview: blocks use full-bright lighting, original textures and colors, and no surface tint, while the existing outline colors stay unchanged. Hidden faces between adjacent ghosts are culled, and depth is written directly so water and clouds keep the correct ordering without flicker or raster artifacts. Valid and invalid previews are still distinguished by outline color only.
- The committed blueprint selection outline changed from orange to light blue, so it is easy to tell apart from the expand (pale yellow) and shrink (light red) previews.
- The blueprint build ghost outline is now green when the materials are enough to build (previously blue); it stays red when the materials are missing.
- The blueprint build ghost now appears 4 blocks in front of you by default instead of 8. Scrolling still adjusts the distance, and the ghost is still pushed away when it would collide with you.
- The blueprint build ghost can now be moved between 2 and 32 blocks away (previously 2-20).
- Quick Build reach increased from 40 to 64 blocks; a single build is still capped at 4096 blocks.
- The blueprint record and build distance limit increased from 40 to 64 blocks.
- The Diamond Blueprint Box is now crafted from a Gold Blueprint Box + 8 diamonds, and its capacity changed from 135 slots (15×9) to 108 slots (12×9).
- The Netherite Blueprint Box capacity changed from 162 slots (18×9) to 144 slots (16×9). Slots beyond the new capacity are not kept, so take out those items and the blueprint before updating.

### Fixed

- Fixed outline lines appearing very dark when another rendering mod left the global color modulator at a non-white value. Chain Mining, Quick Build, and Blueprint Draw now restore the shader color before drawing outlines, and ghost-block rendering restores render state in a `finally` block.
- Fixed Iris compatibility for outline rendering: custom lines now use an immediate `ByteBufferBuilder` source instead of Iris's deferred `FullyBufferedMultiBufferSource`, so they are drawn in the correct render stage with the intended state.
- Fixed the Chain Mining target block box being only one pixel wide on drivers that clamp GL line width: it is now built from cuboid beam quads, following Create's Super Glue outline approach.
- Fixed the Blueprint selection-area preview becoming uniformly dark or changing brightness under Iris shaders: the selection range now uses outline-only preview, matching Create's Super Glue, so the world keeps its normal shader lighting. The build ghost also uses real world lighting.
- Fixed the Automatic Refill page slots not showing item tooltips: hovering a whitelist or inventory slot now shows the item tooltip.

### Removed

- Removed the Obsidian Blueprint Box and its recipe; the Diamond Blueprint Box now upgrades from the Gold Blueprint Box, and explosion resistance is provided by the diamond and netherite tiers. Existing obsidian boxes are not converted automatically, so take out their items and blueprint first.

## 中文

> 对应模组版本：`1.21.1-1.1.2`  
> 适用环境：Minecraft 1.21.1 + NeoForge 21.1.265+ / Java 21  
> 测试范围：仅原版环境（单人游戏 / 内置服务器）  
> 安装位置：客户端与服务端

### 新增

- 物品切换新增**指定行 / 循环**两种模式：指定行（默认）可选择背包第 1-3 行；循环让背包三行和快捷栏按“第一行 → 第二行 → 第三行 → 快捷栏 → 第一行”轮换，也可以改为倒序。两项都在 **Alt + X → 物品切换** 中设置。循环模式始终轮换背包三行和快捷栏，“交换行”只在指定行模式下生效；两种模式都不需要打开背包，也不会触发自动补充；切换模式和循环方向会和其他设置一样按玩家保存，已有玩家数据沿用默认的**指定行 + 正序**。

### 修改

- 连锁破坏、快速建造和蓝图绘制的准星跟随目标统一使用 `0.020F` 的 cuboid 粗框；正在操作的选区 / 规划预览也使用 `0.020F`，已确定的蓝图选区和可见前缘轮廓使用更细的 `0.010F` cuboid 粗线。快速建造和蓝图绘制在选下第一个点后、第二个点确定前隐藏跟随框。
- 蓝图建造虚影改为参考 Create 蓝图预览：方块使用满亮光照、原始贴图和颜色，不叠加表面色；现有轮廓线颜色保持不变。按相邻虚影剔除隐藏面，并直接写入深度，保证水面 / 云层前后关系正确，同时避免闪烁 / 光栅纹。有效 / 无效预览仅通过轮廓线颜色区分。
- 蓝图绘制中已确定选区的轮廓颜色由橙色改为浅蓝色，仍然和新增（浅黄）、删除（浅红）预览容易区分。
- 蓝图建造的虚影轮廓在材料足够、可以建造时由蓝色改为绿色；材料不足时仍为红色。
- 蓝图建造虚影出现时的默认距离由视线前方 8 格改为 4 格；滚轮仍可调整，会碰到玩家时仍会自动推开。
- 蓝图建造虚影的可调距离范围由 2-20 格扩大到 2-32 格。
- 快速建造的目标点最远距离由 40 格提高到 64 格；一次最多建造方块数仍为 4096。
- 蓝图记录 / 建造的操作距离上限由 40 格提高到 64 格。
- 钻石蓝图箱合成改为金制蓝图箱 + 8 个钻石，容量由 135（15×9）调整为 108（12×9）。
- 下界合金蓝图箱容量由 162（18×9）调整为 144（16×9）。容量缩小后，超出新容量的槽位不会保留，升级前请先取出其中的物品与蓝图。

### 修复

- 修复其它渲染模组遗留颜色调制状态时，连锁破坏 / 快速建造 / 蓝图轮廓线整体发暗的问题；绘制轮廓前会恢复白色着色，虚影渲染也会在 `finally` 中恢复渲染状态。
- 修复与 Iris 的轮廓渲染兼容性：轮廓线改用独立的立即绘制 `ByteBufferBuilder`，不再经过 Iris 的延迟 `FullyBufferedMultiBufferSource`，避免在错误的渲染阶段被绘制而变暗。
- 修复连锁破坏的瞄准方块框在部分显卡驱动上只能显示 1 像素细线的问题：参考 Create 强力胶，改为用 cuboid 边条 QUADS 生成有实际宽度的粗框。
- 修复蓝图选区在只点下第一个点、尚未点第二个点时整片预览亮度异常的问题：选区范围改为只绘制轮廓，不再复制区域方块虚影，和 Create 强力胶一致，因此不会让 Iris 重新处理整片虚影；建造模式虚影也使用真实光照。
- 修复自动补充设置页的槽位没有悬停提示的问题：鼠标移到白名单或背包 / 快捷栏槽位上会显示物品信息。

### 移除

- 移除黑曜石蓝图箱及其合成表，钻石蓝图箱改为由金制蓝图箱升级；防爆等级改由钻石及以上提供。已存在的黑曜石蓝图箱不会自动转换，请先取出其中的物品与蓝图。
