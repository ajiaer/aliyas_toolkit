# 1.0.1 — Minecraft 1.21.1

> 对应模组版本：`1.21.1-1.0.1`  
> 适用环境：Minecraft 1.21.1 + NeoForge 21.1.265+ / Java 21  
> 测试范围：仅原版环境（单人游戏 / 内置服务器）  
> 安装位置：客户端与服务端

## 新增

- 蓝图箱物品界面与 `BlueprintBoxItemContainer`：主手拿着蓝图箱按 `Alt + 右键` 即可打开与方块版相同的界面，直接读写蓝图箱物品上的容器 / 方块实体组件。
- 蓝图建造模式 1（绘制）与模式 2（建造）的独立交互流程：没有蓝图时进入绘制模式，已有蓝图时进入建造模式；箱子里没有物品时可以切换模式并覆盖旧蓝图。
- 蓝图绘制吸附键（默认 `Left Shift`，可改键）：选点吸附到指向方块外侧面。
- 自动收集流体设置，默认开启，可在 `Alt + X → 蓝图建造` 页面切换：用空桶收集水 / 岩浆等流体源头并作为蓝图材料。
- 蓝图箱等级、容量、合成 / 升级路线与物品界面支持完整保留。
- 蓝图箱记录时过滤蓝图箱方块与容器内的蓝图箱物品，并提示跳过数量。
- 蓝图箱容器内容作为建造材料，并在建造后放回原容器原槽位。
- 蓝图记录覆盖方块状态、方块实体、容器内容和流体源头。
- 中英文配置页详细说明翻译（配置项 tooltip 不再回退到英文注释）。
- `OrderedKeyMapping`：按键绑定页按功能页顺序排版，打开设置快捷键排第一。

## 修改

- 蓝图建造动作栏提示缩短，只保留当前模式、必要错误和结果反馈。
- 蓝图绘制颜色调整：
  - 已确定选区：橙色；
  - 扩选预览：浅黄色；
  - 缩选预览：浅红色；
  - 动态预览优先覆盖静态选区。
- 蓝图虚影：
  - 材料不足也可进入建造预览；
  - 玩家与虚影碰撞只在刚放出时检测一次；
  - 搜索合法位置半径从 4 格扩大到 8 格；
  - 找不到合适位置时不再反复提示。
- 蓝图模式中的鼠标滚轮只用于调整虚影距离，不切换快捷栏。
- 默认快捷键调整：
  - 旋转虚影：`V`；
  - 退出蓝图建造：`` ` ``；
  - 吸附键：`Left Shift`。
- 模组中文名统一使用 **Aliya的工具包**，不翻译 `Aliya`。
- 版本号改为 `<Minecraft 版本>-<模组版本>`，例如 `1.21.1-1.0.1`。

## 修复

- 修复蓝图记录时把蓝图箱方块一起收进蓝图箱的问题。
- 修复容器方块被剪切后，容器内容已收进蓝图箱却又额外掉落一份的问题。
- 修复蓝图箱界面按钮、滚动和材料行为在物品版与方块版之间不一致的问题。
- 修复蓝图记录中蓝图箱物品可被嵌套收集的问题。
- 修复配置页 tooltip 在中文环境显示英文说明的问题。
