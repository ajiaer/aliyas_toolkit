# Minecraft 1.21.1 - 1.1.3

[English](#english) | [中文](#中文)

## English

> Mod version: `1.21.1-1.1.3`  
> Environment: Minecraft 1.21.1 + NeoForge 21.1.265+ / Java 21  
> Testing: vanilla-like environment only (singleplayer / integrated server)  
> Installation: client and server

### Added

- **Blueprint box fluid tank** (2000 mB on the base box, doubling up to 64000 mB on netherite; standard mB units): a vertical gauge in the top-right of the box screen. Stored fluid is drawn in the fluid's own color, the part the blueprint still needs is drawn in a pale version of the same color, and unused capacity keeps the disabled slot color.
- **Tank tooltip:** hovering a fluid section shows the fluid name, the stored amount out of the tank capacity, and the blueprint requirement; the hovered section widens so it stands out.
- **Bucket interactions:** with an empty bucket, clicking a fluid section takes out one bucket (1000 mB); with a filled fluid bucket, clicking anywhere on the tank stores one bucket when there is room.
- **View toggle button** left of the tank, styled like the recipe book button (raised by default): raised shows the box materials, pressed shows the items stored inside containers in the blueprint. Special containers such as shulker boxes are not expanded. Both columns accept items.
- **"Record Container Items" option** in the blueprint page (on by default): turn it off to record structures whose containers are empty; containers emptied by a cut drop their items on the spot instead of losing them.
- **Chain mining blacklist page**: the toggle under the chain limit turns the preset area into an inventory-style grid (5 rows visible out of 16, with a scroll bar) listing the blocks that use the preset plan. Defaults include stone, cobblestone, deepslate, netherrack, end stone, dirt, and other common massive blocks.
- **Delete / Add buttons under the blacklist**: left click selects a block (moderate red background), right click deselects, and Delete removes the selection. Add temporarily closes the screen, marks the targeted block with the same thick white outline used by chain mining, and adds it when you left click; the back key returns without adding.
- **Quick build default distance**: when your crosshair is not pointing at a block, the indicator appears at a configurable distance in front of you. Hold **Ctrl** + scroll while quick build is on to change it between 2 and 8 blocks (default 2); the action bar shows the new distance.

### Changed

- Blueprint box capacities stay at 27 / 45 / 63 / 81 / 108 / 144 slots; the container-content column has its own capacity per tier: 9 / 18 / 27 / 36 / 45 / 54 slots.
- The three blueprint box buttons (Clear / Quick Take / Store All) moved from the top of the right column to the right of the player inventory.
- Recording a blueprint in cut mode now stores fluid sources in the tank instead of consuming empty buckets. If the tank cannot hold all of them, a message shows the required and available amounts and the blueprint is not created.
- Building takes fluid from the tank instead of requiring buckets in the box.
- Container contents are no longer a hard material requirement. Put the recorded items into the second column and they are restored into the built containers slot by slot; missing items simply stay missing and never block a build.
- The tank never holds more than the blueprint needs for each fluid; adding more, or a fluid the blueprint does not use, shows a message.
- Tank colors now come from the fluid texture's average color multiplied by its tint, and build previews draw fluid sources as translucent blocks in the same color.
- The view toggle is redrawn as a vanilla-style square button with a chest icon, and the three buttons on the right are narrower. The chest icon sits one pixel higher so it looks centered.
- Recording is rejected when the container contents need more slots than the content column can hold: a message shows the needed and available slot counts and no blueprint is created, so nothing is truncated or left behind.
- Chain mining and quick build preset switching now use **Alt + scroll** while the feature is active, instead of holding Z / C and scrolling.
- Which blocks use the preset chain plan now comes from the per-player blacklist instead of the built-in block tag, so every block can be added or removed freely.
- The settings tabs are a little narrower and the divider moved left, giving the right-hand content more room.
- The "Massive Blocks" heading is gone from the chain mining page, so the preset row moves up into that space.
- The blacklist scroll bar groove is one pixel wider on the right, lining up with the thumb.
- The blueprint box tank no longer has an outer black frame: it uses a 1-pixel black top/left edge and a 1-pixel white bottom/right edge like a vanilla slot.
- The three blueprint box buttons (Clear / Quick Take / Store All) moved left so their right edge lines up with the tank.
- Key bindings: "Swap Hotbar with Inventory Row" is now "Item Switching", "Rotate Ghost" is now "Rotate Preview", and the blueprint draw keys are listed before the build keys.
- Shulker boxes and similar containers are recorded the vanilla way: the blueprint only stores the shulker box item (with its own container component), not the items or positions inside it. The box shows the filled item, taking it out keeps the contents, and building applies them back.

### Fixed

- Fixed the container-content column reusing the materials column's row count: the second column now shows only its own rows (one row on the base box, two on copper, and so on) and rows beyond its capacity are neither drawn nor clickable.
- Fixed the container-content column leaving a 1-pixel border under the cells and a black line at the bottom of the area when it has only a few rows (for example the base blueprint box); netherite boxes were not affected.
- Fixed cutting a placed shulker box losing the items inside it; the contents are now kept with the recorded container and restored when the blueprint is built.
- Fixed the blueprint build ghost being covered by clouds, and chests / fluid sources showing every face: the ghost now renders after the clouds and keeps only the nearest face, so you only see the side that faces you.

## 中文

> 对应模组版本：`1.21.1-1.1.3`  
> 适用环境：Minecraft 1.21.1 + NeoForge 21.1.265+ / Java 21  
> 测试范围：仅原版环境（单人游戏 / 内置服务器）  
> 安装位置：客户端与服务端

### 新增

- **蓝图箱流体储罐**（基础 2000 mB，逐级翻倍，下界合金 64000 mB，标准 mB 单位）：界面右上角一条竖着的刻度条。已存流体用流体本身的颜色显示占比，蓝图需要但还没放进去的部分显示同色浅色，未使用的部分保持禁用底色。
- **储罐提示**：鼠标悬停在某一段流体上，会显示流体名称、当前存量 / 储罐容量和蓝图需求；悬停的一段会加宽突出。
- **桶交互**：手上拿着空桶时，点击某一段流体可以取出 1 桶（1000 mB）；手上拿着液体桶时，点击储罐任意位置可以存入 1 桶（前提是有足够空间）。
- **切换按钮**（储罐左边，样式类似配方书按钮，默认凸起）：凸起显示蓝图箱材料，按下显示蓝图内容器里的物品；潜影盒等特殊容器不展开。两栏都可以放入物品。
- **“记录容器内物品”开关**（蓝图建造页，默认开）：关闭后记录的结构里容器都是空的；剪切时容器里的物品会掉在原地，不会凭空消失。
- **连锁破坏黑名单页**：连锁数量下面的“黑名单”按钮点下后，下面的预设区换成类似物品栏的格子（可见 5 行、共 16 行，带滚动条），列出使用预设连锁方案的方块。默认已放入石头、圆石、深板岩、下界岩、末地岩、泥土等常见大量方块。
- **黑名单下方的“删除”“添加”按钮**：左键选中方块（适中的红色底色）、右键取消选中，点“删除”把选中的移出黑名单。点“添加”会暂时关闭界面，准星指向的方块显示和连锁破坏一样的白色粗框，左键点它即可加入；按返回键直接返回、不添加。
- **快速建造默认位置距离**：准星没有指向方块时，指示器会出现在身前的可调距离处。快速建造开启时按住 **Ctrl** + 滚轮可在 2-8 格之间调整（默认 2 格），动作栏会显示当前距离。

### 修改

- 蓝图箱容量保持 27 / 45 / 63 / 81 / 108 / 144 格；第二栏（容器内容物）另有独立容量：9 / 18 / 27 / 36 / 45 / 54 格。
- 蓝图箱界面的三个按钮（清空蓝图 / 一键取出 / 一键存入）从右栏上方移到玩家物品栏右边。
- 剪切模式记录蓝图时，流体源头改为收进储罐，不再消耗空桶；储罐装不下时提示需求 / 容量并**放弃创建蓝图**。
- 建造时从储罐取流体，不再需要在蓝图箱里准备桶。
- 容器内容物不再是硬性材料：把记录的物品放进第二栏后，建造时会按原容器、原槽位回填，缺货的部分直接空着，不阻止建造。
- 记录蓝图时，容器内容物超出第二栏容量会提示“需要多少格 / 只有多少格”并取消记录，不截断、不跳过。
- 储罐里每种流体的存量不会超过蓝图需求：装到上限、或存入蓝图不需要的流体时会提示。
- 储罐颜色改为“流体贴图平均色 × 染色值”，建造预览里的流体源也用同样的颜色显示为半透明方块。
- 第二栏切换按钮重绘为原版风格的小方按钮（中间箱子图标），右侧三个按钮宽度收窄；箱子图标上移 1 像素，视觉上更居中。
- 连锁破坏和快速建造切换预设的快捷键改为 **Alt + 滚轮**（对应功能开启时生效），不再是按住 Z / C 滚动。
- 哪些方块使用预设连锁方案改为由每名玩家的黑名单决定（不再使用内置方块标签），任意方块都可以自由加入或移出。
- 设置界面左侧的功能按钮变窄、中间分隔线左移，右侧内容区更宽；预设行的名称按钮也跟着变宽。
- 连锁破坏页去掉“大量方块”那一行标题，预设行整体上移填补空出来的位置。
- 黑名单物品栏的滚动条滑槽右侧加宽 1 像素，与滑块对齐。
- 蓝图箱储罐去掉最外层黑框，改为左上 1 像素黑边、右下 1 像素白边（和原版凹槽一致）。
- 蓝图箱的三个按钮（清空蓝图 / 一键取出 / 一键存入）左移，右侧与储罐右侧对齐。
- 快捷键名称调整：“快捷栏与背包指定行交换”改为“物品切换”，“旋转虚影”改为“旋转预览”；蓝图箱下方的快捷键改为先列绘制相关、再列建造相关。
- 潜影盒这类特殊容器改用原版逻辑记录：蓝图只保存潜影盒物品本身（含它自己的容器组件），不记录里面的物品和位置。蓝图箱里显示的就是装好物品的潜影盒，取出后内容完整，建造时再按这个物品把内容放回去。

### 修复

- 修复第二栏沿用第一栏行数的问题：第二栏现在只按自己的容量显示行数（蓝图箱 1 行、铜制 2 行……），超出容量的行不绘制、也不能放入或取出。
- 修复第二栏行数较少时（例如普通蓝图箱）格子下方残留 1 像素黑边、区域最下方有一条黑色宽线的问题；下界合金蓝图箱不受影响。
- 修复实体潜影盒被剪切后箱内物品消失的问题；内容物现在随容器一起记录，建造时会重新放回。
- 修复蓝图建造虚影被云层遮挡、以及箱子等实体方块和流体源显示全部面的问题：虚影改为在云层之后渲染，并只保留最近的面，只看得到朝向自己的那一面。
