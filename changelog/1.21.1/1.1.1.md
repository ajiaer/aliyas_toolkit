# Minecraft 1.21.1 - 1.1.1

[English](#english) | [中文](#中文)

## English

> Mod version: `1.21.1-1.1.1`  
> Environment: Minecraft 1.21.1 + NeoForge 21.1.265+  
> Testing: vanilla-like environment only (singleplayer / integrated server)

### Highlights

- **Blueprint recording is split into cut and copy**: `Ctrl + left-click` records the structure, collects materials, and clears the source blocks; `Ctrl + right-click` records the blueprint only and leaves the source blocks untouched.
- **Automatic Refill settings page:** the whitelist and player inventory now use the vanilla chest slot style, matching the blueprint box screen.
- **Quick Build / Blueprint Draw target preview:** before the first point is selected, the target under the crosshair is shown so it is clear that the mode is active.

### Added

- A dedicated `Ctrl + left-click` shortcut for drawing mode (rebindable): records the structure, collects block items, container contents, and fluid buckets into the blueprint box, and clears the source blocks, equivalent to a cut.
- `Ctrl + right-click` in drawing mode now records the blueprint only (copy): it does not take materials or remove source blocks.
- Quick Build displays a green target outline under the crosshair before the first point is selected.
- Blueprint Draw shows a pale-yellow target outline before the first point; after the first point, expand previews stay pale yellow and shrink previews turn pale red.
- A unified exit key (default `` ` ``, rebindable): Chain Mining, Quick Build, and Blueprint Build can all be exited with the same shortcut.

### Improvements

- The existing blueprint entry prompt now directly reports the current mode as **Blueprint Build: Draw Mode** or **Blueprint Build: Build Mode**.
- Quick Build no longer draws a separate thick outline for the first point after it is selected; only the planned range is shown until the second point is set.
- Blueprint build ghosts are slightly more opaque, and back faces / hidden faces between adjacent ghost blocks are culled. The blueprint outline remains fully visible.
- The whitelist, player inventory, and hotbar slots on the Automatic Refill page now use the vanilla chest slot appearance instead of flat colored rectangles.
- Blueprint drawing hints now explain the difference between `Ctrl + left-click` (cut) and `Ctrl + right-click` (copy).

### Behavior notes

- Both recording actions require an empty blueprint box (no stored items) and exit drawing mode; an existing blueprint is replaced by the new one.
- Cut mode collects materials, consumes empty buckets when applicable, and removes source blocks. Copy mode only stores the blueprint; source blocks and the box contents are unchanged.
- With automatic fluid collection enabled in copy mode, fluid sources are recorded in the blueprint, but the matching buckets must be supplied later when building.
- The Automatic Refill page change is visual only; whitelist data, slot behavior, and existing saves are unchanged.

### Fixed

- Fixed blueprint drawing being unable to re-add an area after it had been removed with left-click selection. Selection changes are now applied in operation order, so a later add overrides an earlier removal.

### Compatibility and testing

- Target environment: Minecraft 1.21.1 / NeoForge 21.1.265+ / Java 21.
- **Tested only in a vanilla-like environment**: singleplayer and the integrated server. Other mods, dedicated multiplayer servers, and large modpacks are untested.
- The mod is designed to be installed on both the client and the server.

## 中文

> 对应模组版本：`1.21.1-1.1.1`  
> 适用环境：Minecraft 1.21.1 + NeoForge 21.1.265+  
> 测试范围：仅原版环境（单人游戏 / 内置服务器）

## 版本亮点

- **蓝图记录拆分为剪切 / 复制**：`Ctrl + 左键` 记录并收取材料，同时清除源方块；`Ctrl + 右键` 只记录蓝图，源方块保持不变。
- **自动补充设置页视觉优化**：白名单和玩家物品栏改用原版箱子界面的槽位样式，和蓝图箱界面保持一致。
- **快速建造 / 蓝图绘制目标跟随预览**：第一次选点前也能看到准星指向的目标轮廓，方便确认功能已开启。

## 新增

- 蓝图绘制新增独立快捷键 `Ctrl + 左键`（可改键）：记录结构，把方块、容器内容和流体桶收进蓝图箱，并清除源方块，相当于剪切。
- `Ctrl + 右键` 在绘制模式下改为“只记录蓝图（复制）”：不拿取源方块和材料，蓝图箱只保存结构定义。
- 快速建造开启后、第一次选点前，目标格会跟随准星显示绿色轮廓。
- 蓝图绘制进入后、第一次选点前，目标格会跟随准星显示淡黄色轮廓；选定第一个点后，扩选预览保持淡黄色，缩选预览切换为淡红色。
- 新增统一退出键（默认 `` ` ``，可改键）：连锁破坏、快速建造、蓝图建造都可以用同一个快捷键退出。

## 改进

- 进入蓝图模式时，原有进入提示会直接显示“蓝图建造：绘制模式 / 建造模式”。
- 快速建造在选中第一个点后不再单独绘制第一个点的粗框，第二个点确定前只保留规划范围轮廓。
- 蓝图建造虚影透明度略微提高，并启用方块背面 / 相邻隐藏面剔除：玩家看不到的面不再绘制，建造轮廓线仍正常显示。
- 自动补充设置页的白名单、玩家背包和快捷栏槽位改用原版箱子界面的槽位外观，与蓝图箱界面保持一致，不再使用纯色方块绘制。
- 蓝图绘制提示同步说明 `Ctrl + 左键`（剪切）和 `Ctrl + 右键`（复制）的区别。

## 行为说明

- 两种记录方式都要求蓝图箱没有物品，并且会退出绘制模式；已有蓝图会被新蓝图覆盖。
- 剪切模式会按原有逻辑收取材料、消耗空桶并移除源方块；复制模式只保存蓝图，源方块不变，也不会向蓝图箱放入材料。
- 复制模式下，自动收集流体开启时，流体源头会作为蓝图内容记录；之后建造时仍需自行准备对应的桶。
- 自动补充设置页只调整外观，不改变白名单数据、槽位功能或原有存档兼容性。

## 修复

- 修复蓝图绘制中先用左键删除区域、之后再用右键框选同一区域时无法将其加回来的问题。选区现在按添加 / 删除操作顺序生效，后一次操作会覆盖前一次。

## 兼容性与测试说明

- 目标环境：Minecraft 1.21.1 / NeoForge 21.1.265+ / Java 21。
- **仅在原版条件下测试**：单人游戏与内置服务器；未测试其它模组组合、专用多人服务器和大型整合包。
- 客户端与服务端设计上都需要安装本模组。
