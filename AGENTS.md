




# 特殊文件夹、文件夹
| 相对路径                    | 说明                     |
| --------------------------- | ------------------------ |
| changelog                   | mc版本对应的更新日志     |
| changelog\index.md          | 日志总览                 |
| docs                        | 其它文档                 |
| docs\release\description.md | 网站发布时使用的描述内容 |



# 注意事项
- 除非特意说明，更新日志应放到对应mc版本最新的日志文档里
